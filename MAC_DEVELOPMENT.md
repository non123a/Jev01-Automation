# JEV01 Mac Development

This branch is experimental development for JEV01-Automate.

Environment:
- Apple Silicon Mac
- macOS
- Python 3.14
- SQLite
- No direct MT5 Python integration

Purpose:
- Develop and test JEV01 core logic
- Test liquidity detection
- Test sweep detection
- Test structure detection
- Test candidate generation
- Test JEV decision logic
- Use deterministic/replay data where necessary

Important:
- This branch may change architecture based on test results.
- Do not assume experimental logic is production-ready.
- Windows MT5 integration will be validated separately.
- Merge back to main only after Windows/MT5 validation.

The experimental design is allowed to change when testing reveals problems.
